## 分析單位與隨機效應

分析單位 = 預測條目;使用者 = 隨機效應(同一人多條預測不當獨立樣本)。

## 命中率定義(逐字)

- 命中率 = `occurred+hit / occurred`。
- `absent` 不進分母(情境沒出現 = 無資料)。
- `occurred` 且未交第 2 段 = **缺測**(不進分母、不當 miss — 掉答不得向下偏命中率)。
- `occurred+miss`、`occurred+other` **只進分母、不算命中**。

## 通過門檻(三指標並陳,逐字)

真實組 − 對照組命中率 **≥ 5 個百分點(對應 r ≥ .10 / d ≥ 0.20)且 p < .05(雙尾)**。

- 加嚴參考檔:**7.5pp / r = .15 / d = 0.30**。
- 同時報告兩組**絕對命中率**(證明非 Barnum 基礎率)。
- **負差顯著 → 視同主張被推翻**,觸發 §1 主張下修;不得僅當「再調規則」。

## 回饋率差異必檢

回饋率 = 該組 `occurred` 列中完成第 2 段提交的比例(`absent` 不進分母)。
兩組回饋率差異顯著 → 差值反映回報意願而非預測效度,**該批資料作廢**。

## 「批」的定義

- 批 = 自然曆週(Asia/Taipei 週一開始,同 F5 cycle)。
- 分析以**全部累積資料**執行(不挑時點、不許期中停樣)。
- 首批分析門檻:兩組合計 `occurred` ≥ 50 列。

## 指派機制(登記)

- 逐槽(domain 槽位)獨立 25%:`secure_bytes(1)[0] % 4 == 0`(CSPRNG;256 整除 4,無模偏誤)。
- 中籤槽位以「其他使用者的**最新** complete profile」(每人取最新一列後隨機抽)走完全相同管線。
- **逃生口**(皆降級為該槽真實組,登記於此):池中無其他 complete profile;
  被抽列資料損壞(重抽至上限 3 次);洗牌向量零命中;crypto 不可用。
- 逃生口使上線初期對照占比低於 25% — **所有可指派週一律 ITT 全數計入**,
  不排除低密度週。
- 槽位指派對使用者盲(事前);事後解盲 = 週級聚合摘要(逐條指認已裁決降級,
  見切片 rev.2 對帳 — 防對照列辨識線索污染回饋行為)。
