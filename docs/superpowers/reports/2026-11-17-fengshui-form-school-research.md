# 形勢派風水 × 預測大腦 — 研究統整（2026-11-17）

> 站長裁示（同日）：風水負責**引興趣**，預測大腦負責**差異化**。換派：八宅（理氣）parked → 形勢派（巒頭）。
> Guardrail 放寬到「兩種說法並列、互不背書」：**傳統怎麼說 / 你的大腦怎麼看這個空間**；不得寫成腦科學證明風水。
> 本報告由三路研究統整（主張盤點、證據對照、產品形態），關鍵文獻已由 Claude 抽查。大部分文獻只讀摘要或二手轉述，引用到產品文案前須回原文核對。

## 0. 一句話結論

形勢派主張裡，**「看得到、可預期」那一半有中等以下的研究支持，「靠、壓、沖」那一半幾乎沒人測過**；預測處理（PP）能當詮釋框架，但沒有任何研究檢驗過任何一條風水主張。
這反而是產品的核心價值：把每條傳統主張變成**一個可以拿自己空間去對答案的假說**，而不是先相信。

## 1. 形勢派 vs 理氣派的邊界（判準）

- **形勢派（納入）**：只靠照片或平面圖就能判斷的幾何關係——靠、對、沖、壓、開闊、方正、光、動線。
- **理氣派（排除）**：凡需要羅盤度數、出生資料、年份時辰，或把八卦／五行對應到人與事（命卦吉方、財位度數、文昌桃花、流年飛星、缺角對應家人、水火相沖、擇日）。
- 原典可依者很少：《葬書》「氣乘風則散，界水則止」「明堂逼塞不寬舒」、四靈（原文講墓穴，「皆自穴處言之」）已在維基文庫核對；**室內具體禁忌幾乎都是近代港台通行說法或西方 BTB，未查得原典**——文案須照實標示。
- 學術錨點：Kryžanowski (2019, *Urbani izziv* 30(2):124–134, DOI 10.5379/urbani-izziv-en-2019-30-02-006) 比對 118 條形勢派建議：45%（53 條）與環境心理學全部或部分一致，34% 與 Pattern Language 一致，23% 兩者皆一致；其餘多依附「氣」而無法檢驗。（Claude 已核對摘要數字；118 條明細待讀全文。）

## 3. 預測大腦（PP）能放進來的方式

- **可用**：Peters, McEwen & Friston (2017) 把壓力定義為無法消解的不確定性；Djebbara 等人（2019 PNAS、2021 Sci Rep）證明大腦在移動前就預測空間可供性（門寬過不過得去）；Djebbara, Parr & Friston (2020) 提出建築經驗的預測框架。→ 可說「大腦隨時在預測環境，看得清楚、可預期的空間，**理論上**比較不需要額外警戒」，並標明是假說。
- **不可用**：FEP/PP 幾乎什麼結果都能事後講通（Andrews 2021 等批評）→ **PP 只能當詮釋語言，不得當證據**；任何一條主張的「大腦欄」證據強度只能取自環境心理學實證，不能由 PP 提升。
- **真正的差異化**：PP 的核心是「拿預測去對答案」。產品可以讓使用者**先預測**某個改動（如床換位、坐位改看得到門）對自己的影響，**再體驗、回報**——這把風水從「信不信」變成「自己的空間自己驗」，與站上 F5 的預測迴圈同構。（具體是否做成迴圈、做多重，留待設計階段裁示。）

## 4. 文案紅線（並列表達）

1. 「傳統」欄照實標來源層級：有原典／通行說法未查得原典／西方 BTB。
2. 「大腦」欄只陳述研究測了什麼、強度多少；沒研究就寫「目前沒有研究直接測過」。
3. 兩欄之間**不得**出現「所以」「證實」「科學解釋了」等連接詞或宣稱。
4. 刪除疾病／婚姻／破財／死亡的身體對應與意象（出殯格、相罵門、對到哪病哪），改中性空間描述。
5. 不推薦購買任何化煞物品；只給零成本的空間調整（移位、屏風、關門、整理）。
6. 理氣成分一律不進本功能。

## 5. 產品形態（推薦 B，分兩期）

| | A 純問答 | **B 模板＋視覺化問答，照片選用輔助（推薦）** | C 平面圖拖拉 |
|---|---|---|---|
| 可靠度 | 高 | 高（以使用者確認為準） | 位置最高，立體特徵仍要問答 |
| 工程量 | 小，零 AI 零上傳 | v1 同 A；v2 加照片 | 大（Leptos 自寫 SVG 拖拉、手機調校） |
| 隱私 | 幾乎無 | 照片選用、不落庫、剝 EXIF、清場提示 | 低 |
| 差異化 | 低 | **高**：市面拍照 app 是黑盒、回通用建議 | 中高 |

- **v1**：房型模板（臥室／書房）＋每題附示意 SVG 的問答 → 結果卡逐項並列兩種說法。零 AI、零上傳。
- **v2**：選用照片，AI 只預填或標記「疑似樑／尖角／雜物」，使用者逐項確認。
- 技術依據：
  - 單張照片判斷相對位置在學術上不可靠（SpatialRGPT、TopViewRS、SpatiaLQA）。
  - 站上 vision 走 Workers AI，Scout 在手相 spike 被評為幾何弱。
  - 手相管線約七成可複用：上傳縮圖、不落庫只存特徵、限流退款、AIMutexDO 專屬實例、知情同意。
  - 要改的部分：多張照片（`build_messages` 只能帶一張）、新 schema 與 prompt、隱私文案升級。
  - CSP 注意：預覽要用 data URL，`blob:` 會被擋。

## 6. 待裁示

1. 產品形態：B 方案分兩期（v1 無照片）是否同意。
2. 主張範圍：v1 建議收 F01–F17、F19、F23 中「室內、臥室／書房可判」的子集；F18、F21、F22 不收。
3. 預測迴圈：v1 結果卡是否加「先猜後試」（預測一個改動 → 一週後回報），或先只做並列卡。
