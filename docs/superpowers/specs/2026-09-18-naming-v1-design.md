## 1. 五格公式（康熙筆畫；已鎖定，來源：熊崎氏主流，Plan agent 查證）

| 格 | 單姓雙名 (王小明) | 單姓單名 (李白) | 複姓雙名 (歐陽小明) | 複姓單名 (歐陽鵬) |
|---|---|---|---|---|
| 天格 | 姓+1 | 姓+1 | 姓1+姓2 | 姓1+姓2 |
| 人格 | 姓+名1 | 姓+名 | 姓2+名1 | 姓2+名 |
| 地格 | 名1+名2 | 名+1 | 名1+名2 | 名+1 |
| 外格 | 名2+1 | 2（固定虛畫 1+1） | 姓1+名2 | 姓1+1 |
| 總格 | **各字筆畫總和（不含虛畫）** | 同左 | 同左 | 同左 |

- 恆等式 `天+地 == 人+外` 恆成立；**總格 ≠ 四格相加**（李白 7+5=12；四格和 28）。
- 天格＝祖傳，不單獨論吉凶（五行仍入三才）→ UI 加註。
- 單名地格＝名+1（假成一）；單姓單名外格＝2 → UI 加註「吉凶意義有限」。
- **>81 wraparound**：`while n > 81 { n -= 80 }`；81 查自身條目（還本歸元），非 `81→1`、禁用 `n % 81`（82→2 不是 1）。減 80 不改個位數 → 五行不受影響。
- 數理五行（十天干序）：個位 1,2=木 3,4=火 5,6=土 7,8=金 9,0=水。

## 2. 三才 v1 簡化規則（designer 決策，刻意非古表）

配置 = 天格五行、人格五行、地格五行（三字，如「土金木」）。
評級只看相鄰兩對（天↔人、人↔地），每對：比和或相生（任一方向）= 和諧；相剋 = 衝突。
兩對和諧 → 吉；一和一衝 → 半吉；兩衝 → 凶。

**失真聲明（必須出現在 UI）**：本表為生剋簡化規則，非傳統 125 組配置表。已知失真代表例（測試以 snapshot 鎖定）：
- 金金金：古表多凶（過剛），簡表 = 吉
- 木木土：古表常大吉，簡表 = 半吉（木剋土）
- 洩氣局（我生）當和諧：金水木、土金木 等古表常凶，簡表偏樂觀
