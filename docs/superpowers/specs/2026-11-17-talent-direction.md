## 1. 四句根基(站長 2026-11-17 確認)

1. **天賦 = 學得快的地方。** 證據形態是學習速度(外部效標:實際進度、實際上手程度),
   不是喜好自陳。資優鑑定、外科實證、語言性向研究皆以學習速率為判準。
2. **證據 = 真實體驗。** 天賦沒試過不會顯現(PP 語言:生成模型與環境結構的契合度,
   要接觸才冒出來);自陳問卷問的是想像中的自己,量不到做事時的表現。
3. **命盤 = 候選清單產生器。** 紫微星曜/西洋宮位本身就是一套「你可能有什麼傾向」的
   敘事系統;命盤給假說,真實體驗給證據,兩邊對照。命盤不是判決,是待驗證的預測
   ——與「傾向非注定」guardrail 同向,與 F5「預測→回報實況」同構。
4. **一切宣稱可檢驗。** 產品的科學性不在引用哪個理論,在結構本身可檢驗(有外部效標、
   可被體驗反駁)。PP 強版(自由能原理)同樣被批不可證偽,故 PP 只是設計靈感,
   不是產品地基。

## 2. 平台定位(站長語)

「做為一個算命的網站幫助人理解自我,至為關鍵。」差異化:別家命理/心理測驗賣
不可檢驗的標籤,本站賣可檢驗的探索。這條 DNA 已存在於工程:F5 一次性回饋、
遮罩、情境鎖;F8 對照組盲測——都是「讓宣稱可被檢驗」的實作。天賦線是同一 DNA
的延伸,不是新發明。

## 3. 設計哲學(沿用既有裁示)

- **隱性 PP**:結構用,語言不用——介面不說「大腦/預測誤差/理論」(禁詞紅線)。
- **可檢驗性 = 結構屬性**:每個對使用者的宣稱都要能被真實體驗反駁。
- **不貼死標籤**:輸出是「候選+證據+更新」,不是「你是 X 型」。

## 4. 尚未決定(產品形態設計階段展開)

- 候選清單怎麼來(命盤哪些構面 → 哪些可嘗試的領域;語料工程)。
- 「學得快」怎麼在個人內測量(無組間常模 → 相對比較設計)。
- 體驗怎麼記、證據怎麼呈現、與人格卡/命盤頁/首頁的接點。
- RIASEC 下架(Batch 0)併入新線時點。

## 5. 已知風險(方向層級,待 Opus 方向審補強)

1. 「學得快」的可操作化:無常模下只能個人內對比(你學 A 比學 B 順)——是特性也是
   限制,設計要正面處理,不能假裝有組間比較。
2. 天賦標籤的固定心態風險(Dweck):呈現方式若暗示「天生注定」就違反根基 4,
   也違反 guardrail。
3. 可檢驗文化與命理用戶期待的張力:誠實是差異化,也可能拆命理自己的台——
   GUARDRAIL「傾向非注定」已處理此張力,新功能沿用其精神。
