## 1. 四句根基(站長 2026-11-17 確認;v2 依審修訂措辭)

1. **天賦 ≡ 操作定義為「相對學得快」。** 這是本站的產品選擇,不是科學定論。誠實登錄:
   反證存在(Koedinger 等 2025:先備知識預測的是起點,學習速率本身驚人地一致——
   觀察到的快慢大部分是先備與機會差異);學習速度受動機、教學品質、脈絡混淆。
   此定義比照「隱性 PP」處理:內部設計理由用,對外文案禁引任何文獻背書。
2. **證據 = 真實體驗,且必須是具體、有界、可列舉的訊號**(完成了什麼、產出什麼、
   卡在哪)。禁止蒐集「速度感」自評;速度只能是具體訊號的衍生摘要。原因:自主探索
   中「實際進度」終將自報,自報只有框限成具體訊號才站得住(F5 的二值判斷是先例);
   「證據不足」必須是產品中真實存在的 UI 狀態,禁止在證據薄時編造更新感。
3. **命盤的角色 = 待裁示**(§4 路徑 a/b/c)。唯一確定:命盤不判決、只給素材,
   與「傾向非注定」guardrail 同向;其效度定位(受檢宣稱/敘事層/不進測量線)須先裁。
4. **一切宣稱可檢驗。** 產品的科學性不在引用哪個理論,在結構本身可檢驗(有外部
   效標、可被體驗反駁、宣稱粒度=證據粒度)。PP 強版同樣被批不可證偽,故 PP 只是
   設計靈感,不是產品地基。本線的「最小可反駁單位」須在設計階段首先定義——F5 的
   保護機制(遮罩/一次性回饋/情境鎖)可搬運的是原則,不是機制。

## 2. 平台定位(站長語)

「做為一個算命的網站幫助人理解自我,至為關鍵。」
**宣稱分層條款**(v2 新增):對外差異化文案只說「本站這條線可檢驗」,不得全稱對比
「別家賣不可檢驗的標籤」——本站命盤解讀類表面依 guardrail 定位為「非宣稱的反思
素材」,兩者認識論地位不同,不得互打。各表面須能標明自身地位。

## 3. 設計哲學(硬規則,v2 擴充)

1. **隱性 PP + 隱性文獻**:結構用,語言不用;介面不說「大腦/預測誤差/理論/研究指出」。
2. **不貼死標籤**:輸出是「候選+證據+更新」;每則速度觀察必須帶時間與條件標記
   (「在這段嘗試裡」);結論必須有更新/撤銷的結構位置。
3. **宣稱粒度規則**:只在有證據的粒度上輸出;粗粒度結論須明示「尚未支持的類化」。
4. **速度訊號禁轉推薦權重**:速度只用於排序已探索項目,不得成為未探索領域的推薦
   權重(否則 = 上游研究警告的繭房路徑,系統性回報既有優勢、錯殺起步慢者)。
   探索多樣性(取樣未探索/低分領域)是結構要求,不是文案選項。
5. **永不生成負面能力宣稱**:含隱含比較;候選清單必明示「非窮盡,未列≠不適合」
   (補集推論是命理脈絡下最毒的負面自我實現預言)。
6. **最低證據量原則**:證據未達門檻只輸出「目前觀察」,不輸出總結級宣稱。
7. **對象 = 本人**:對外明示為本人的自主探索,防代測(家長拿小孩命盤測天賦)。
8. **AI 若進場**:GUARDRAIL 逐字適用、prompt 語言測試守門(CLAUDE.md 規則);
   v1 預設不接 AI。

## 4. 待站長裁示(設計前必須定)

**A. 假說來源/命盤效度定位**(Opus A-1 + F-1/F-2,同一決策的三條路):

- **路徑 a — 命盤候選 = 受檢宣稱**:命盤產生候選清單,其效度本身納入 F8 式對照+
  預先登記+負結果處置承諾。最雄心;但 F8 已示範這是數週級成本,且 D6 首批分析
  (2026-09-13 預登至今)尚未收割——一人團隊養第二條檢驗線的順序風險高。
- **路徑 b — 命盤 = 純敘事層**:候選由中立策展的跨領域微體驗池供給(多樣性/難度
  標定可控),命盤只做敘事呼應,零效度主張。最穩;差異化與「命理網站」的品牌
  連結最弱。
- **路徑 c — 宣稱者 = 使用者自己**(Claude 推薦):使用者先猜「我學這個會不會快/
  順」→ 實際體驗 → 對答案。命盤不進測量線(最多做路徑 b 式敘事呼應)。這是真
  F5 同構(可檢驗的宣稱者是使用者,不是不可檢驗的命盤);每次預測天然是最小可
  反駁單位,E-1 的粒度問題自動解;「發現自己對自己的預測錯在哪」本身就是自我
  理解,最貼句 2 精神。初版小實驗的結構以此形態回歸,主題換成天賦/上手。

**B. 對外詞彙**(Opus C-2):「天賦」是 GUARDRAIL_ZH 否定對象+interest 掃描禁詞。
建議:留作內部構念名,對外用「上手線索/學得快的地方」級詞彙;或裁示解禁並重劃
掃描範圍(需同步改 interest 測試)。

**C. 順序**(Opus E-2):先收割 D6 首批分析(occurred ≥50 門檻)驗證檢驗迴圈閉環,
再開宣稱級設計?或 v1 即做(路徑 c 的宣稱負擔低,像 F5 一樣每次自反駁,不需 F8 級
rigor,D6 不 block)?

## 5. 已知風險(v2 併 Opus 增補,設計階段逐項對策)

1. 「學得快」是狀態相依快照(先備/動機/教學/階段混淆;初期快後期追上是常態)——
   §3.2 時間條件標記+可撤銷是對策的起點。
2. 個人內對比的方法論坑具名:練習/順序效應、記憶偏差、自評膨脹、新鮮感與速度混淆、
   **任務難度基線不對齊**、歸因偏誤、無對照的確認偏誤。任何「A 比 B 順」的輸出必須
   能回答「是不是難度/順序/新鮮感造成」——答不出就不輸出比較。
3. 馬太效應:測到的快可能是先備機會;§3.4 禁轉推薦是硬規則。
4. 補集推論與代測:§3.5/§3.7。
5. 努力不對稱與證據稀薄期:命理解讀是零努力內容,本線要使用者做事;設計階段必須
   定義最小可行迴圈(做最少的事仍得到非空洞的回報)。
6. 文案治理:「天賦」詞彙三方衝突(guardrail/interest 掃描/本線名稱),§4-B 裁示。
7. 資料劃界:本線是否耦合 symbolic、新表與 F5/F8 測量表隔離宣告、縱貫資料刪除
   語意與保留揭露——設計階段先劃紅線(既有紅線存在理由:防測量線被污染)。
