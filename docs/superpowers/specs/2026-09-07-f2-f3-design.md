## 1. F2 — 命盤象徵傾向

### 1.1 語義

- **全盤制**:有可用紫微盤 → 向量純由紫微計算;否則用西洋;兩者皆無 →
  F2 缺席(`prior = null`),不阻擋 F1/F5。兩盤不混算、不逐維縫合
  (Kimi [13]);**v1 不產西洋並陳文字**(Codex [9]:API 無對應欄位,另立切片)。
  「可用」的定義見 §1.4 命盤解析器。
- 分數 = `clamp(50 + 該維所有命中調整量的平均, 0, 100)`(rev.4:多條命中取平均;
  基準 50 為本切片補洞 —「無命中 = 無資訊」即 50)。
- 內部保留 0–100 實值;**UI 只呈現五檔帶**,不秀裸分(Kimi [10]:±10 粒度
  撐不起兩位數的精度假象)。
- 版本:`SYMBOLIC_RULES_VERSION = "symbolic-1"`,**僅隨 overlay 回應輸出**
  (Codex [9]:story cache key 變更不在本切片,§7 已排除)。規則表內容變更必須 bump。

### 1.2 五維與檔帶

五維與 F1 同尺:E=外向、A=友善、C=嚴謹、S=情緒穩定(高=穩,UI 需標示方向)、
O=智性開放。檔帶(內部分數 s):

| 檔帶 | 範圍 |
|---|---|
| 偏低 | s < 35 |
| 略低 | 35 ≤ s < 45 |
| 中等 | 45 ≤ s ≤ 55 |
| 略高 | 55 < s ≤ 65 |
| 偏高 | s > 65 |

(Kimi [17] 修正:豁免掛「實測值落最低檔」而非固定 33 — 見 §2.2。)

### 1.3 規則表(調整量 ∈ {0, ±10, ±20})

**雙軸標註**(Kimi [14]):每條規則標「依據」= classical(古典星性描述)/
designer(設計裁量);**映射權重一律 designer**(古典文獻不存在 Big5,不得借古典
權威替映射背書)。UI 顯示來源時只顯示「依據」層。

紫微 — 取**命宮主星**;命宮空宮時借對宮主星,**借星調整量上限 |Δ| ≤ 10**
(Kimi [15]:古典「借而減等」)。四化、亮度(廟旺利陷)、身宮 v1 一律不計
(接受的近似;亮度列 v2 第一優先)。

| 主星 | 調整 | 依據 |
|---|---|---|
| 紫微 | C+20,E+10,O−10 | classical;E/O 為 designer |
| 天機 | O+20,S−10,C−10 | classical |
| 太陽 | E+20,A+10 | classical |
| 武曲 | C+20,A−10,E−10 | classical;E 為 designer |
| 天同 | S+20,C−20,A+10 | classical |
| 廉貞 | C+10,O+10,S−10 | classical;S 為 designer |
| 天府 | C+20,S+10,E−10 | classical;E 為 designer |
| 太陰 | E−20,O+10,S−10 | classical;O 為 designer |
| 貪狼 | E+20,O+10,C−10 | classical |
| 巨門 | O+20,A−10,S−10,E−10 | classical;E 為 designer |
| 天相 | A+20,C+10 | classical |
| 天梁 | S+10,A+10,C+10 | classical |
| 七殺 | E+10,A−10,S−10 | classical;S−10 為 designer(剛烈急躁,原稿 S+10 係誤植膽量為穩定,Kimi [1]) |
| 破軍 | O+20,C−20,E+10 | classical |

西洋 — 元素制,太陽 ±20、月亮 ±10、上升 ±10(Kimi [11]:權重沿流行慣例,
理由記錄於此 — 產品以紫微為主,西洋內部權重屬次要;月亮主導情緒維的議題隨

| 元素 | 調整 |

| 火(牡羊/獅子/射手)| E+ |
| 土(金牛/處女/摩羯)| C+ |

(Kimi [8] 的次維擴充 — 風→E+、水→A+、土→S+ — 列 v2 候選:v1 不取,
避免「中等」檔罕見化。)

**聚合公約**(Codex [6] 補洞):規則表未觸及的維**不進分母**(缺席 ≠ 0 貢獻);
某維全無命中 = 50。借星的調整量**在平均之前**逐條 clamp 到 [−10,10]。兩個選擇
各有數值 fixture 釘死(§5):紫微+天府的 O = 40(非 45);借 −20 星以 −10 計。

單一來源單維理論極值 [30,70];clamp 防禦性保留。

### 1.4 資料與 API

- **零新表**。F2 為純函數即時算:`crates/schema/src/symbolic.rs`
  `pub fn symbolic_vector(ziwei: Option<&ZiWeiChartV3>, western: Option<&WesternChartV3>) -> Option<SymbolicVector>`。
  輸入讀既有 `interpretations.chart_data`(紫微優先)。
- **命盤解析器(新服務,小型)**:`resolve_chart(ctx, user) -> ChartResolution`,
  型別化結果 — 抽自 `charts.rs` route closure 的取圖/新鮮度/重算邏輯
  (Codex [4]:現有邏輯嵌在 route 內、`get_birth_data` 私有且回 HTTP Response,
  直接重用會把 304/HTTP 語意帶進來;auth/ETag/HTTP 留在 routes)。
  解析順序:① 有生辰且 gender 存在 → 取**符合當前 birth_data_hash 且版本新鮮**
  的紫微盤;缺席/過期/壞 JSON → 即時重算(經 engine binding);gender 缺失 →
  **跳過紫微、不發明預設值**(Codex [3]:engine client 會靜默 default male、
  route 會 400,解析器明確選擇跳過)。② 紫微不可用 → 同法解析西洋。
  ③ 重算失敗 → 該盤不可用,**絕不回退使用過期盤**。engine/parse 失敗降級為
  「該盤不可用」;DB/auth 失敗維持原 5xx 語意。
- 並發與快取語意(rev.3,計畫審查 Codex [P11] 裁定):v1 resolver **只讀+即時算,
  不寫快取** — 命中新鮮快取即讀;缺/過期/壞 JSON 經 engine 現算但不落
  `interpretations`。重算清 `ai_interpretation` 的副作用與並發寫入問題因此在
  overlay 路徑不存在;重複計算成本可接受。命盤頁自身的寫入行為不變。
- `SymbolicVector { ruleset_version, source: PriorSource(ziwei|western), dims: [f64;5] }`。
- 新端點 `GET /api/personality/overlay`(需 session),詳 §3。

## 2. F3 — 落差洞察

### 2.1 門檻

逐維 `|measured − prior| ≥ 20.0` 才敘事;低於門檻僅並列兩者檔帶。
20 = rev.4 的 2×SEM 操作值(非統計檢定;只排除實測側測量噪聲,命盤側無誤差模型)。
**比對用 `ocean_measured` 實值**(F1 刻意不取整即為此),顯示一律檔帶化。

### 2.2 豁免(全維,非 S 專屬)

實測值落在**偏低檔**(s < 35)的維,該維**一律只並列檔帶、不敘事** — 不論
差距多大。此為 rev.4「高神經質者 S 維不敘事」的全維超集(Kimi [19]),且數學上
可達(Kimi [17] 證明固定 33 閾值在 F2 規則下為死規則,已廢)。內部命名
`narrative_ok`,不用臨床詞。

### 2.3 動線(opt-in)

- 填生辰、F1 完成後,**不自動顯示**;`/personality` 結果頁出現「查看命盤象徵對照」
  入口,點擊後先顯示說明,再展開疊圖:
  說明文案(定稿):「命盤象徵傾向」來自出生盤的傳統星性對照,「實測人格」來自你
  剛完成的人格測驗。兩條線來源不同,不一致很常見;不一致不代表你有缺陷,也不
  代表你需要改變。只有兩者差距夠大時,我們才會描述那個落差。
- **資格判定矩陣**(Codex [2] 補洞;先於命盤解析執行):取**最新一列** profile
  (`created_at DESC, rowid DESC`)的 `measurement_status`:
  `skipped_prior_only` → 409 `F3_DISABLED`;`careless_suspected` → 409
  `MEASUREMENT_PENDING`(該狀態無 `ocean_measured` 可用);無任何 profile →
  409 `NO_MEASUREMENT`;`complete` → 採用該列量測。歷史結果的重新查看**不**改變
  資格判定。F5 自身的 profile 選擇不在本切片更動。
- 無任何命盤(解析器回 null)→ `prior = null`,僅顯示實測檔帶。
- D4:F3 永久免費。

### 2.4 措辭與禁用詞

- 敘事模板(描述式,rev.4 措辭規範;**以檔帶措詞,不用二分高低** — Codex [5]:
  prior 落「中等」時「偏高/偏低」會失真):「在{維度}上,命盤象徵落在
  {priorBand},你的實測落在{measuredBand}。象徵是傳統對照,實測是你作答的
  結果;這段落差只是描述,不含評價,也不暗示該怎麼改。」負向傾向一律「在某些
  情境下表現為…」框架,並與一個正向面向並陳(Kimi [21])。
- 禁用詞表(模板、log、prompt、變數名一體適用):神經質、憂鬱、焦慮症、診斷、
  病態、缺陷、低能、人格障礙、違背天性、壓抑本性。**例外**:§2.3 經你核可的
  安撫說明文案為白名單 — 禁用詞約束的是生成式斷言,不是人審過的固定文案
  (Codex [9])。
- 模板與檔帶文案上線前**真人審一遍**(上線檢核項,rev.4 L242)。

## 3. API 形狀

`GET /api/personality/overlay`(session 必需):

```json
{
  "rulesetVersion": "symbolic-1",
  "priorSource": "ziwei" | "western" | null,
  "dims": [
    {
      "dim": "extraversion" | "agreeableness" | "conscientiousness" | "stability" | "openness",
      "measured": 61.7,
      "prior": 60.0,            // null = F2 缺席
      "priorBand": "略高",       // null = F2 缺席
      "measuredBand": "略高",
      "gap": 1.7,
      "narrativeOk": false,
      "text": "…" | null        // null = 不敘事
    }
  ]
}
```

錯誤:409 `NO_MEASUREMENT` / `F3_DISABLED` / `MEASUREMENT_PENDING`。
**契約**(Codex [5]):`gap = prior 為 null 時 null,否則 abs(measured − prior)`;
`narrativeOk = prior 在場 && gap ≥ 20.0 && 實測非偏低檔`;`text != null ⟺
narrativeOk`。**維度順序**恆為 E,A,C,S,O 恰五項不重複,位置向量與 wire 一致;
wire 欄位名固定 `extraversion/agreeableness/conscientiousness/stability/openness`
(F1 的 `emotionalStability`→`stability`、`intellectImagination`→`openness` 映射
寫死單處;Codex [8])。檔帶在 wire 上用穩定 enum code
(`low/mid_low/mid/mid_high/high`),中文標籤由單一共享函數輸出;v1 文案語言
固定 zh-TW。回應整體可快取鍵:`(user_id, birth_data_hash, ruleset_version,
最新 complete profile id)` — v1 先不落快取,純即時算(量小)。

## 5. 測試(TDD 不變式;native 與 runtime 分離 — Codex [7])

**原生純測試**(native target;斷言領域結果,不是 Worker `Response` 物件 —
wasm/js_sys 限制見 CLAUDE.md):

- 規則表:值域 ⊆ {0,±10,±20};十四主星全覆蓋;西洋 12 星座 × 3 體全覆蓋;
  借星**逐條 clamp 後**平均(數值 fixture:紫微+天府 O = 40 非 45;借 −20 以
  −10 計 — Codex [6])。
- `symbolic_vector`:雙星同宮平均、空宮借星、紫微缺席→西洋、皆無→None、source。
- 檔帶邊界 fixture:35→略低、45/55→中等、65→略高(精確邊界)。
- overlay 決策純函數:`narrativeOk` 全組合 — gap=20 敘事 / 19.9 不敘事、
  **兩個差值方向都測**、豁免(實測偏低檔)壓過大 gap、prior=null 全不敘事
  (Codex [5])。
- F5 紅線(§0.4 修訂版):F5 選則輸出回歸測試釘死;`predictions.rs` 不 import
  `symbolic` 以編譯單元結構保證。
- 維度順序/映射斷言、DTO 序列化(nullable prior/gap)。

**運行時驗收**(部署後 `scripts/verify` 或手動,不進 native — Codex [7]):

- overlay session 強制、409 三態實測、過期快取重算、gender 缺失跳紫微、
  engine 失敗降級、並發重複計算容忍。
- 前端:opt-in 動線、說明文案、F2 缺席兩態文案。
