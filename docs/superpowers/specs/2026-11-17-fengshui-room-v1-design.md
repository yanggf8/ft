## 0. 定位與站長裁示

- **風水負責引起興趣，預測大腦負責差異化。**
- 對照**現代風水**（港台與現代室內風水通行說法），不追古籍。
- 每張卡並列「**風水怎麼說**」與「**研究怎麼說**」，互不背書（站長 2026-11-17 裁示改名：原「你的大腦怎麼看」名實不符，內容是環境心理學研究，不是腦科學——Fable F05）。
- **預測大腦由互動承載，不由內容承載**：
  - 「翻卡先猜」：你先預測研究現況，再對答案（即時的預測誤差）。
  - 「先猜後試」：你先預測一個調整對自己的影響，再觀察（延遲的預測誤差）。
  - 卡片內容不得用預測處理（PP）補「大腦理論上會…」的故事；PP 只出現在說明卡，且明講它是解讀框架、不是證據。
- 理氣成分（命卦、吉方、財位、文昌、桃花、流年飛星、羅盤、五行、缺角對應家人）一律不收。
- 站長是第一個使用者；每批以站長自己用得下去、且理解正確為驗收。

## 1. 規則集（`FENGSHUI_ROOM_RULESET_VERSION = "1"`）

房型：`bedroom`（臥室）、`study`（書房／工作位），題目各自獨立。每題單選，必有「不確定」（`unknown`）。每題附俯視示意 SVG，選項可直接點圖。

狀態 `ok | mild | flag | unknown`；同為 flag 但風水說法或證據不同者以變體區分，各有自己的卡。**沒有分數、總評、吉凶等級。**題目不用無依據的精確距離。

**臥室**

| id | 題目 | 選項 → 狀態（變體） |
|---|---|---|
| `bed_back` | 床頭後面是什麼？ | 實牆 → ok；窗 → flag(`window`)；門或走道 → flag(`passage`)；沒靠牆 → flag(`floating`) |
| `bed_door_view` | 躺在床上，看得到房門嗎？ | 看得到、門在斜前方 → ok；門正對床尾 → flag(`facing`)；看不到門 → flag(`hidden`) |
| `bed_overhead` | 床的正上方有什麼？ | 沒有 → ok；外露的樑 → flag(`beam`)；吊櫃、層板或大型吊燈 → flag(`heavy`) |
| `bed_mirror` | 躺著時，鏡子照得到你嗎？ | 照不到 → ok；照得到 → flag |
| `bed_corner` | 床旁邊有沒有柱角、牆角或櫃角，尖端朝著床？ | 沒有 → ok；有 → flag |
| `bed_door_door` | 房門和其他房門正對嗎？ | 沒有 → ok；正對 → flag |
| `bed_light` | 晚上睡覺時，房間能暗下來嗎？ | 能 → ok；外面的光會照進來 → flag |
| `bed_clutter` | 地面和床底下的雜物多嗎？ | 很少 → ok；有一些 → mild；很多 → flag |

**書房／工作位**

| id | 題目 | 選項 → 狀態（變體） |
|---|---|---|
| `seat_back` | 坐著時，椅背後面是什麼？ | 實牆 → ok；窗 → flag(`window`)；門或走道 → flag(`passage`) |
| `seat_door_view` | 坐著時看得到房門嗎？ | 在視線內、不正對 → ok；正對著門 → flag(`facing`)；背對門 → flag(`hidden`) |
| `seat_overhead` | 座位上方有外露的樑嗎？ | 沒有 → ok；有 → flag |
| `seat_front` | 桌子前方是開闊的嗎？ | 開闊或有窗景 → ok；直接面對很近的牆 → flag |
| `seat_corner` | 座位旁邊有尖角朝著你嗎？ | 沒有 → ok；有 → flag |
| `seat_light` | 白天座位的自然光夠嗎？ | 夠 → ok；不太夠 → flag |
| `seat_clutter` | 桌面和周圍的雜物多嗎？ | 很少 → ok；有一些 → mild；很多 → flag |

純邏輯：`crates/schema/src/fengshui/`——`ruleset.rs`、`corpus.rs`、`evidence.rs`、`mod.rs`（`assess(room, answers) -> Vec<Card>`）。native 可測；web 直接呼叫 ft-schema，全程不經 API（塔羅 v1a 先例）。

## 2. 卡片語料（`FENGSHUI_ROOM_CORPUS_VERSION = "3"`；2＝Batch 2.1，3＝徽章文字修正）

卡片單位：`(itemId, 狀態, 變體)`。

### 2.1 卡片結構

1. **風水怎麼說**（≤100 字）：一律用引述句型（「風水的說法是……」「風水師常建議……」）。可以引述**溫和後果**（睡不安穩、心神不寧、不易放鬆、容易分心）；**不可**引述疾病、婚姻、財務、死亡意象（Fable F06）。說法分歧照實寫「各家說法不一」。
   - 題目是為了配合研究而改寫的（`bed_light`），風水欄照實揭露題目與「明廳暗房」原意相近但不完全一樣（Fable F03；試玩後改為使用者語氣）。`seat_light` 直接引用現代風水「書桌宜採光充足」的通行說法，不需揭露（Batch 1 審稿修正）。
2. **研究怎麼說**（≤140 字）：只陳述研究測了什麼、在什麼結果上（偏好評分、睡眠、情緒、注意力……）、限制；沒有研究就寫「目前沒有研究直接測過」，不再補任何推想。
3. **研究徽章**（只在「研究怎麼說」欄內，**每張卡都有**，翻開後才看得到）。Batch 2.1（2026-11-19，站長裁示）推翻 Fable F01 的「ok 卡不顯示徽章」：主徽章改成「研究站在哪一邊」，會照實寫出「相反」「沒差異或不一致」，徽章本身不再預設是支持；ok 卡另加「符合常見建議」小標，並保留限制說明。
4. **可以試試看**（僅 flag／mild）：`adjustments: [{id, text}]`，每卡 1–3 個，每個 ≤60 字（Fable F10）。不買化煞商品的低成本調整，優先：關門、用現有布簾或家具、整理一小區、調整枕頭方向；涉及大型家具加「量力而為，不要獨自搬重物」。

### 2.2 研究徽章（Fable F01/F19；Batch 2.1 加立場軸）

**主徽章：立場 `stance`**（翻卡先猜的答案，§3）：

- `same`「和風水同方向」
- `opposite`「和風水相反」
- `mixed`「沒差異或不一致」
- `untested`「沒人測過」（⇔ `reach = none`，測試守門）

判定規則：以 `refs` 中**最具體測到該配置**的研究方向為準；只有籠統研究（如瞭望－庇護文獻彙整）時看其結論。只看結果方向，不管測的結果變項是否和風水說法相同——落差一律由 `limitation` 寫出。研究欄寫到「相反」的卡，立場只能是 `opposite` 或 `mixed`（測試守門）。

**副徽章：`reach`**，加一句限制說明：

- `direct`「有研究直接測過這個特徵」
- `related`「只有相關研究」（2026-11-19 試玩：引用的不全是空間研究，原「只有相關的空間研究」改掉）
- `none`「目前沒有研究直接測過」

徽章下一行是 `limitation` 短句，必須寫出**測的是什麼結果**，例如「測的是座位偏好評分，不是睡眠或壓力」。效果量、樣本、設計放在「看研究」展開區。

### 2.3 初值（下限；升級需 ledger 佐證——Fable F02）

2026-11-18 依證據帳本（`docs/superpowers/reports/fengshui-research/evidence-ledger.md` §4）＋站長裁示更新；標 ★ 者與初版不同。

立場欄為 Batch 2.1 新增（同方向 14、相反 2、不一致 13、沒人測過 9，共 38 張；以前「永遠猜只有相關研究」可猜對 74%，現在任一選項最多 37%）。ok 卡的 reach 與同題 flag 卡相同。

| 卡 | stance | reach | limitation 要點 |
|---|---|---|---|
| `bed_back` ok／passage | mixed | related | 瞭望－庇護研究測的是空間偏好評分，室內研究多為中性 |
| `bed_back` window／floating | same | related | 瞭望－庇護研究測的是空間偏好評分，文獻彙整（計票）結果不一致；window／floating 另引平面圖擺床實驗（Spörrle 2010），測的是擺床偏好，不是睡眠 |
| `bed_door_view` ok | mixed | related | 83% 選看得到門（同方向），但多數人選床尾朝門那面牆（和「不要正對」相反）|
| `bed_door_view` hidden | same | ★ direct | 測的是在平面圖上擺床的偏好，不是睡眠（Spörrle 2010，138 人，83% 選看得到門；Bonin 2023 重現研究未讀全文，列延伸） |
| `bed_door_view` facing | opposite | ★ related | 唯一相近的擺床實驗結果方向相反（多數人選床尾朝門那面牆）；平面圖不能斜擺，測的是偏好不是睡眠 |
| `bed_overhead` 全部 | untested | none | 橫樑與頭頂重物都沒有研究；天花板高度研究（Meyers-Levy 2007）沒測到舒適感差異、封閉空間研究（Fich 2014，只讀摘要）操弄牆面開口，皆列延伸閱讀 |
| `bed_mirror` | untested | none | 不引用 Tamaki 2016（首夜效應，與鏡子無關） |
| `bed_corner`、`seat_corner` | mixed | related | 測的是看圖片的喜歡評分；統合分析中室內空間類圖片效果為零，真實桌椅研究（2025）沒有重現 |
| `bed_door_door` | untested | none | |
| `bed_light` | mixed | related | 題目與風水原意不同（§2.1）；測的是開燈睡與睡眠（Mason 2022，20 人）；「外面照進來的光」在大型問卷研究（Sweeney 2023）中結果偏弱 |
| `bed_clutter`、`seat_clutter` | same | related | 研究測的是導覽自家的用字與妻子的壓力荷爾蒙型態、情緒；只有相關、不能推論因果；沒有測床底或桌面；Roster 2016 未讀不引用 |
| `seat_back` ok、`seat_door_view` ok／hidden | mixed | related | 測的是座位使用率與偏好／自評專注，不是壓力或門本身；觀察研究（Psathiti 2017）中背向走道的座位反而最常被坐 |
| `seat_back` window | mixed | related | 只引瞭望－庇護（研究欄另寫，不提走道研究）|
| `seat_back` passage | opposite | related | 觀察研究中背向走道的座位反而最常被坐 |
| `seat_door_view` facing | same | ★ related | 觀察研究中正面直視主要走道的座位較少人坐；對象是走道不是門 |
| `seat_overhead` | untested | none | 同 `bed_overhead` |
| `seat_front` | same | related | 注意力恢復（認知測驗，小到中度）與窗景（術後恢復）研究；沒有測「面牆」 |
| `seat_light` | same | related | 有窗與睡眠的小樣本研究（49 人）；測的是睡眠與自評生活品質，不是專心 |

`direct` 目前只有 `bed_door_view` hidden 一張（2026-11-18 依證據帳本＋站長裁示），而且測的是平面圖上的擺床偏好、不是睡眠；其餘都只有相關研究或沒有研究——這本身就是要讓使用者看見的事實。

### 2.4 證據帳本（Kimi K03、Fable F18）

`evidence.rs` 是唯一來源，每篇文獻：`key`、作者年份期刊、URL、`design`、`n`、`outcome`、`limitation`、`full_text_read: bool`。`docs/superpowers/reports/fengshui-research/evidence-ledger.md` 只寫敘述與核對筆記。

規則：`reach` 升為 `direct` 時，所引用文獻必須全部 `full_text_read == true`（T6 守門）。卡片文獻分兩欄：`refs`（研究欄所依據、徽章以此為準）與 `further`（延伸閱讀，例如只讀到摘要者）；`direct` 卡的 `refs` 不得含未讀全文者（2026-11-18）。研究欄每句話都要能對到一篇文獻。

### 2.5 說明（兩個位置）

- **開場一句**：「每一項會並列風水的說法和相關研究。下面這些研究多數不是為了檢驗風水而做，有些項目根本沒有人研究過。」（Fable F04 修正「說太滿」）
- **結果最後的說明卡**：
  1. 唯一直接比較過風水佈置的實驗：Zijlstra et al. 2024（PLOS ONE，N=558，線上看病房的影片與圖片，不是 VR）——風水佈置讓房間顯得較愉悅，對焦慮沒有直接效果；限制是線上、非真實住院、15 處同時改動無法分離、共同作者之一隸屬國際風水協會（Fable F04；2026-11-18 依證據帳本 §4.2）。
  2. 預測大腦是什麼；它只是解讀框架，不是證據。
  3. 「你剛剛翻卡前的猜測和答案的落差，就是一次預測誤差」（接 §3）。
  4. 「你的預期本身也會影響你的感受」（接 §4）。

### 2.6 文案紅線（測試＋人工審稿）

- 禁用詞（分段、以片語比對，並有白名單片語避免誤殺「不能證明」「不意外」——Fable F06）：
  - 背書：證實、證明、科學解釋、科學根據、研究印證、腦科學支持、所以風水、磁場、能量
  - 恐嚇：凶、不吉、不祥、血光、破財、漏財、財運、離婚、影響婚姻、生病、有損健康、災厄、意外、運勢、出殯、相罵、小人、口舌、陰氣、衰、犯小人、招
  - 化煞商品：八卦鏡、山海鎮、五帝錢、葫蘆、水晶、貔貅、風鈴、化解、開運、旺
  - 理氣：命卦、吉方、財位、文昌、桃花、流年、飛星、羅盤、五行、缺角
  - 白名單片語（允許）：「不能證明」「不是在證明」「沒有證實」「不意外」
  - 「煞」只能出現在風水欄，作為術語引用。
  - 測試範圍涵蓋卡片、開場句、說明卡、翻卡與先猜後試的所有固定文案。
- **人工審稿閘門**：語料定稿前 Claude 逐卡兩欄對讀審一次，再給站長；Batch 2 上線前看手機實機畫面，確認徽章不會被讀成「這條風水有研究支持」。
- 長度以 `chars().count()` 測試；每題每個非 unknown 狀態／變體都要有卡。

### 2.7 版本規則

使用者看得到的卡片文字、徽章、limitation、文獻語意改動 → bump `FENGSHUI_ROOM_CORPUS_VERSION`；題目、選項、判定改動 → bump `FENGSHUI_ROOM_RULESET_VERSION`。

## 3. 翻卡先猜（Batch 2，站長裁示加入——Fable F21；Batch 2.1 改版）

答完問答後，**每一題作答過的卡**（flag／mild／ok）都先以**蓋牌**呈現：只顯示「風水怎麼說」，研究欄蓋住。順序 flag → mild → ok；ok 卡標「符合常見建議」、沒有「可以試試看」。

1. 每張卡先猜：「研究站在哪一邊？」四選一：和風水同方向／和風水相反／沒差異或不一致／沒人測過。
2. 翻開：主徽章顯示立場、副徽章顯示 reach，下一行 limitation（立場為「沒人測過」時只留主徽章，避免同一句重複三次）；標示猜對或猜錯，猜錯時一句「你原本以為……，實際是……」。
3. 全部翻完：「你猜對 X / Y 張」＋參考基準「隨便猜大約會對 1/4。」，並接說明卡（§2.5 第 3 點）。
4. 可以「全部直接翻開」略過遊戲。
5. 全部 ok 時，頂端一句「你回答的項目都符合常見風水建議。符合建議不代表研究也站在同一邊，一樣可以猜猜看。」
6. 純前端；猜的結果只存在當下的頁面狀態，不落 localStorage、不上傳。

設計原則：猜的對象是**這條風水說法**，和使用者的房間擺得好不好無關，所以 ok 卡也能玩。

**Batch 2.1 改版理由（2026-11-19 試玩）**：舊版猜「研究做到哪了」（reach 三選一），flag／mild 卡中 17/23 是 related，永遠猜它就有 74% 命中，是必勝策略；而且舊版只翻 flag／mild 卡，房間大致符合風水的人完全玩不到，最有意思的研究（Spörrle 83%）反而藏在 ok 卡。新的猜測軸分布較平均，也比較容易猜錯，例如以為研究支持「背後不要是走道」，翻開才發現背對走道的座位最常被坐。

## 4. 先猜後試（Batch 3，純前端——站長裁示，Fable F08）

### 4.1 範圍

- 資料只存在瀏覽器 `localStorage`（`fengshui_obs_v1`），不登入、不上傳、不跨裝置。
- spec 明文：這套流程**不保護任何測量**，只是給自己的觀察工具；遮蔽是降低錨定，不是保密。
- 每個房型同時最多 1 個進行中的觀察。

### 4.2 流程

1. 在 flag／mild 卡的某個調整上按「試試看」。
2. 提示「先做完這個調整，再按開始」——**開始時間＝調整完成時間**（Fable F07）。
3. **起點**（調整前的過去 7 天），0–10 分，兩端錨點：
   - 安心感：「待在這個位置你覺得多安心？」（0 很不安心 … 10 很安心）
   - 功能感：臥室「睡得好嗎？」（0 很差 … 10 很好）；書房「能專心嗎？」（0 很難 … 10 很容易）
4. **預測**：每題猜一個**區間**——「調整後這段時間，你猜會落在 〔 〕 到 〔 〕」，可以猜維持或變差（站長裁示，Fable F09）。
5. 開始後顯示開放倒數（7 天）；30 天後過期。提醒只顯示日期；`.ics` 下載為加分項，iOS 實機不穩就拿掉（Fable F22）。
6. **回報**（調整後這段時間）：
   - 先問「這段時間你有維持這個調整嗎？」（有／部分／沒有）
   - 再答兩題 0–10。回報時起點與預測都不顯示，送出後一起揭曉。
7. **對答案**：顯示起點、預測區間、實際；標示「落在你猜的區間內／外」。
   - 固定說明：「預測和實際的落差，可以當作一個觀察線索。一次的結果分不出是調整、你的預期、生活上的其他變化，還是評分本身的起伏造成的，所以它不能說明這個調整有沒有用，也不能說明風水對不對。」
   - **沒有維持調整時**另用文案：「這段時間你沒有調整，分數還是變了 X。這就是平常的起伏有多大。」（Fable F07）
8. **校準紀錄**：累計「落在自己區間內」的比例（例如「你的預測 5 次中有 3 次落在區間內」），讓使用者看到自己的預測準不準。只用自己的資料，不做跨使用者比較。

UI 用語是「自我觀察」，不用「實驗驗證」。

## 5. 前端

- `/fengshui`（公開）：開場一句（§2.5）＋「答案只存在這個瀏覽器，不會上傳」→ 選房型 → 問答（俯視圖點選、進度條、可返回）→ 翻卡先猜 → 說明卡。
  - 答案存 `localStorage` `fengshui_room_v1_{room}`；開場與結果頁都有「清除我的房間答案」。不設 TTL（明文取捨：個人裝置為主）。
- 結果頁：作答過的卡全部蓋牌，順序 flag → mild → ok（ok 卡標「符合常見建議」）；unknown 收進「還不確定的項目」折疊（Batch 2.1）。
- 卡片：手機上下排、桌機左右並列；「看研究」展開文獻。
- Batch 2 的卡片只顯示「可以試試看」文字，**不放按鈕**；按鈕在 Batch 3 隨觀察功能一起上（Fable F16）。
- Batch 3：`/fengshui` 內加「我的觀察」區（進行中附倒數、可回報、已完成、過期、校準紀錄、清除）。
- 首頁 feature-grid 加入口；名詞解釋加「風水」分類（樑壓、明堂、門對門等），bump glossary 版本。
- SVG 以 Leptos `view!` 內嵌繪製，不引入外部 JS（CSP）。色彩沿用現有 token；新色票照色彩紅線重採玻璃底對比。

**ft-schema（native）**
- T1 規則集完整：每個選項都有狀態；題目 id 不重複；變體只出現在 flag。
- T2 語料完整：每題每個非 unknown 狀態／變體都有卡；flag／mild 卡有 1–3 個調整、id 不重複。

- T6 徽章：每張卡都有 `stance`、`reach` 與非空 `limitation`；`untested` ⇔ `none`；立場與 §2.3 表一致；研究欄寫「相反」者立場只能是 opposite／mixed；flag／mild 必有調整、ok 卡無調整；`direct` 的引用文獻全部 `full_text_read`；引用的文獻 key 都存在。
